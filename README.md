**ByteSpace** is a modern, premium frontend landing page for an educational tech and design platform. It features beautiful UI/UX components, dynamic 3D floating elements, and a fully responsive layout built exactly to Figma design specifications.

## 🚀 Live Demo

[View the live project here!](https://byte-space-new-bay.vercel.app/)

## ✨ Key Features

- **Pixel-Perfect Implementation:** 100% fidelity to the provided Figma design.
- **Responsive Layouts:** Custom-tailored layouts for both mobile devices and desktop views.
- **Interactive UI:** Features hover effects, floating cards, and dynamic UI elements.
- **Modern Tech Stack:** Built for speed with React, TypeScript, and Vite.
- **Tailwind CSS:** Comprehensive custom design system using utility classes.

## 🛠️ Technologies Used

- **React (v18)**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React**
- **Vercel** (Hosting)

## 💻 Getting Started

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/raisatabassumkabir/ByteSpace-New.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd "ByteSpace New/bytespace-frontend"
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. Open your browser to the local host address provided in your terminal (usually `http://localhost:5173` or `3000`).
